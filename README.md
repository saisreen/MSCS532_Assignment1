# MSCS532 - Assignment 1: Insertion Sort

## Description
This project implements the Insertion Sort algorithm using Python. The program sorts an array of numbers in monotonically decreasing order (largest to smallest).

This assignment is based on Chapter 2 of *Introduction to Algorithms* by Cormen et al. (2022).

## Algorithm
Insertion Sort works by taking one element at a time and placing it in its correct position within the sorted portion of the array.

For decreasing order, larger elements are moved toward the beginning of the array.

## Technologies Used
- Python 3.8 or higher
- Visual Studio Code
- Git and GitHub

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

   `python3 insertion_sort.py`

## Example

**Input:**

`[12, 5, 8, 20, 3, 15]`

**Output:**

`[20, 15, 12, 8, 5, 3]`

## Time Complexity
- Best Case: O(n)
- Average Case: O(n²)
- Worst Case: O(n²)
